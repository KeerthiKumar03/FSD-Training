# 🎓 KS Group – Infinity Academy

A responsive **Student Management System** front-end developed using **HTML5, CSS3, Bootstrap 5, and JavaScript**. This project provides a modern interface for managing student information, registrations, profiles, dashboards, and contact details.

---

## 📌 Project Overview

KS Group – Infinity Academy is a simple academic management portal designed to demonstrate a student management system. The project focuses on providing an attractive, responsive, and user-friendly interface for students and administrators.

---

* 🏠 Responsive Home Page
* 👨‍🎓 Student Registration Form
