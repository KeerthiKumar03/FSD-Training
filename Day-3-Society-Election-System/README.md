# Society Survey and Representative Election Management System

A static multi-page web application developed using **HTML5** and **CSS3** for managing residential society surveys and representative elections.

---

## 📌 Project Objective

This project helps residents of a society to:

- Register and login
- Participate in society surveys
- Vote for representatives
- View candidates
- Check election results
- Contact the society committee

The system is designed with a clean and responsive user interface using modern frontend concepts.

---

## 🚀 Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
