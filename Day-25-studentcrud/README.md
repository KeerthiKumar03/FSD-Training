# 🎓 Student Management System

A responsive Student Management System built using **React.js** and **Bootstrap**. This project demonstrates CRUD operations, searching, and sorting functionality using React Hooks and state management.

## 🚀 Features

* ➕ Add New Students
* ✏️ Edit Existing Student Records
* ❌ Delete Students
* 🔍 Search Students by Name
* 🔃 Sort Students Alphabetically
* 📋 Display Student Data in Tabular Format
* ⚡ Dynamic UI Updates with React Hooks
* 🎨 Bootstrap-based Responsive Design

## 🛠️ Technologies Used

* React.js
* JavaScript (ES6)
* Bootstrap 5
* CSS

## 📸 Functionalities

Users can add a student by providing:

* Name
* Age
* Grade

### ✏️ Edit Student

Update existing student information.

### ❌ Delete Student

Remove student records instantly.

### 🔍 Search Student

Search students by name using the search bar.

### 🔃 Sort Students

Sort students alphabetically by clicking the Name column.

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/student-management-system.git
```

### Move into the project directory

```bash
cd student-management-system
```

### Install dependencies

```bash
npm install
```

### Run the application

```bash
npm start
```

Open:

```text
http://localhost:3000
```
